# ProxyKit

个人代理资源仓库，用于存放 Loon、Quantumult X、Egern、Surge 可共用的图标、脚本、规则和模块。

## 目录说明

icons：通用图标目录。所有 App 图标、功能图标、品牌图标都放这里，通过文件名区分用途。

loon/plugins：Loon 插件文件，通常是 .plugin 或 .lpx。

loon/scripts：Loon 使用的脚本文件，通常是 .js。

loon/rules：Loon 使用的规则文件。

qx/rewrite：Quantumult X 重写文件，通常是 rewrite、conf 或相关文本规则。

qx/scripts：Quantumult X 使用的脚本文件，通常是 .js。

qx/filter：Quantumult X 分流或过滤规则。

egern/modules：Egern 本地模块，通常是 .yaml 或 .yml。

egern/scripts：Egern 使用的脚本文件，通常是 .js。

egern/rules：Egern 使用的规则文件。

surge/modules：Surge 模块文件，通常是 .sgmodule。

surge/scripts：Surge 使用的脚本文件，通常是 .js。

surge/rules：Surge 使用的规则文件。

## 命名建议

图标文件建议使用英文、数字、短横线或下划线命名，不使用中文、空格和括号。

示例：SleepCycle.png、Mubu.png、WeRead.png、McDonalds.png、Apple.png、RemoveAds.png、Server.png、TencentVideo.png、MangoTV.png、iQIYI.png
